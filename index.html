CHAPTER 02 知能

NEXORA

Digital Behavior Intelligence Engine & Anomaly Detection

An academic BCA and Data Science project engineered as a privacy-preserving telemetry intelligence platform. Models human-computer interaction patterns purely as aggregate velocities, click cadences, and session transitions without storing keystroke characters, passwords, or screenshots.

  • Deterministic cognitive metrics: Focus Index, Continuity Index, and Fragmentation Trend
  • Supervised Random Forest classification into 5 distinct behavioral archetypes
  • Unsupervised Isolation Forest outlier detection to isolate erratic interaction sessions
  • High-performance Flask REST API with SQLite local datastore and live streaming charts
Python 3.12 Flask Scikit-learn Pandas SQLite3 Chart.js
